핵심 유저 플로우
1 · 진입
스트릭 홈
오늘 찍었으면 스트릭 불꽃 🔥 활성화. 안 찍었으면 "오늘 아직 비어있어요" + 큰 셔터 버튼
2 · 행동
한 장의 사진 찍기
카메라 SDK 호출. 찍는 순간 현재 위치 자동 태그. 한 줄 메모 선택 입력
카메라현재 위치
3 · 보상
스트릭 달성
N일 연속 달성 애니메이션. 7일·30일·100일 마일스톤 배지. "내일도 이어가세요" 넛지
4 · 회고
지도 & 캘린더
쌓인 기록을 지도나 캘린더로 회고. 지도는 보상으로만 존재 — 메인이 아님
차별화 포인트 — 왜 사진 앱 대신 이걸 쓰나
의도적 기록 vs 자동 수집
가장 강력한 차별점
핵심
아이폰 사진 앱은 아무 의도 없이 모든 걸 저장함. 영수증 사진, 스크린샷, 음식 사진 전부 섞임.
Streak Map은 "오늘 하루를 대표하는 한 장"을 의식적으로 고르는 행위. 이 선택의 순간 자체가 가치.
유저 멘탈 모델: "사진 앱은 저장소, Streak Map은 일기"
스트릭이 만드는 이탈 방지
Duolingo가 증명한 구조
MVP 필수
Duolingo DAU의 핵심 동기는 언어 학습이 아니라 스트릭 유지. 같은 구조를 사진 기록에 적용.
스트릭이 길어질수록 앱을 지우기 아까워짐 → 자연스러운 Lock-in.
스트릭 보호권 월 1회: 하루 빠져도 유지. 이걸 "아끼는" 심리가 오히려 더 열심히 찍게 만듦.
월말 공유 카드 — 바이럴 엔진
애플 사진 앱이 절대 못 하는 것
2차
애플 추억은 나만 봄. Streak Map 월말 카드는 "나 이번 달 31일 연속 찍었어"를 자랑할 수 있는 포맷.
스트릭 숫자 + 대표 사진 3장 + 간 곳 수 → 1080×1920 카드 → 인스타 스토리 공유.
공유 동기: 사진 자랑이 아니라 습관 자랑. "나 꾸준히 살고 있어"라는 자기표현.
