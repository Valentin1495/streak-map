개요
Streak Map은 토스 미니앱으로, 사용자가 매일 사진을 찍고 위치를 기록하면 누적된 기록이 지도 위에 내 삶의 궤적으로 시각화되는 앱이다. 친구 없이도 첫날부터 의미 있는 경험을 제공하며, 월말 리포트 카드로 자연스러운 바이럴을 유도한다.
핵심 유저 플로우 (MVP)
1
진입
토스에서 미니앱 진입. 위치 권한 + 카메라 권한 요청. 처음이면 온보딩 1장 (스트릭 개념 설명)
→
2
홈 (지도)
내가 찍은 사진들이 지도 위 핀으로 표시. 오늘 아직 안 찍었으면 하단에 "오늘 기록 남기기" CTA 강조
→
3
촬영
카메라 SDK 호출. 사진 찍으면 현재 위치 SDK로 좌표 자동 태그. 한 줄 메모 옵션 (선택)
→
4
저장 & 피드백
지도에 새 핀 추가. 스트릭 +1 애니메이션. "N일 연속 기록 중" 상태 업데이트
5
핀 상세
지도 핀 탭 → 사진, 위치명, 날짜, 메모 확인. 삭제 가능
→
6
통계 탭
현재 스트릭, 총 기록 수, 이번 달 방문 장소 수, 가장 자주 간 곳. 캘린더 히트맵
→
7
월말 리포트
매월 1일 자동 생성. 공유 가능한 카드 이미지 (1080×1920). 카카오/인스타 공유
→
기능 정의
지도 홈
앱의 메인 화면
MVP 필수 현재 위치
핀 클러스터링: 같은 위치 핀이 겹치면 숫자 배지로 묶음. 줌인 시 개별 핀으로 분리.
오늘 기록 여부 표시: 오늘 찍었으면 상단 스트릭 바 활성화. 안 찍었으면 하단 FAB 강조 애니메이션.
타임라인 슬라이더: 날짜 범위 필터로 특정 기간 동선만 보기. (선: 이동 경로 연결 옵션)
촬영 & 기록
핵심 인터랙션
MVP 필수 카메라 현재 위치
카메라 SDK 호출: 앱 내 카메라로 찍거나 앨범에서 가져오기 선택 가능.
위치 자동 태그: 촬영 시 현재 위치 SDK 호출 → 좌표 + 역지오코딩으로 장소명 표시 (예: "강남구 역삼동").
하루 제한 없음: 하루에 여러 장 찍을 수 있음. 단 스트릭은 하루 1회 달성으로 카운트.
오프라인 대응: 위치 못 잡으면 마지막 알려진 위치 또는 수동 입력 fallback.
스트릭 & 통계
리텐션 핵심
MVP 필수
스트릭 로직: 자정 기준으로 당일 기록 여부 판단. 자정 1시간 전 미기록 시 푸시 알림.
스트릭 보호권: 월 1회 사용 가능. 하루 빠져도 스트릭 유지. (리텐션 이탈 방지용)
캘린더 히트맵: GitHub 잔디 스타일. 기록한 날 색상, 기록 수에 따라 진하기 차등.
장소 통계: 이번 달 방문 고유 장소 수, 가장 자주 간 TOP3.
월말 리포트 카드
바이럴 핵심
2차 개발
자동 생성: 매월 말일 자정에 서버에서 생성. 다음날 아침 푸시 알림으로 전달.
카드 내용: 이달의 동선 지도 썸네일 + 스트릭 일수 + 방문 장소 수 + 대표 사진 3장.
공유 포맷: 1080×1920 이미지로 저장 가능. 카카오톡, 인스타그램 스토리 직접 공유.
워터마크: "Streak Map" 로고 하단 고정 → 자연스러운 앱 노출.
앨범 가져오기
과거 기록 채우기
2차 개발 앨범
과거 사진 import: 앨범 SDK로 사진 선택 → EXIF GPS가 있으면 자동 태그, 없으면 날짜만 기록.
스트릭에는 미포함: 과거 import는 지도 기록으로만 추가. 스트릭 소급 적용 없음 (어뷰징 방지).
온보딩 활용: 첫 설치 시 "과거 기록 가져와서 지도 채우기" 유도 → 초기 빈 지도 문제 해결.
기술 제약 & 결정사항
데이터 저장
사진은 서버 저장 필수 (미니앱 로컬 스토리지 한계). 좌표 + 메타데이터는 경량 DB. 사진 용량 제한 검토 필요 (유저당 월 50MB 기준 제안)
지도 렌더링
네이버맵 SDK 사용 (한국 주소 역지오코딩 정확도). 웹뷰 기반이므로 JS 지도 SDK 연동
위치 정확도
실내에서 GPS 약할 때 fallback 처리 필요. 위치 오차 반경 표시 검토. 위치 권한 거부 시 수동 장소 검색으로 대체
푸시 알림
스트릭 유지 알림은 토스 앱 내 푸시 인프라 활용. 사용자가 알림 시간 직접 설정 가능하게 (기본 오후 8시)
